Task Flow is a clean, modern Progressive Web App (PWA) designed to simplify task management and boost daily productivity. Built with an intuitive, responsive interface, it allows users to organize, track, and prioritize their workload seamlessly across both desktop and mobile devices.

Key Features:

Progressive Web App (PWA): Fully installable on desktop and mobile with fast loading and offline capabilities.

Task Organization: Easily create, search, and manage tasks with visual progress indicators and status tracking.

Starred Items: Pin high-priority tasks to keep critical deadlines front and center.

Minimalist Interface: Clean, distraction-free design built for high efficiency and quick navigation.
